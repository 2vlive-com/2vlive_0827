# 2vlive_0827
ทีมชาติไทยพลาดแชมป์ ASEAN Championship หลังเสมอเวียดนาม 2-2 รวมผลสองนัดแพ้ 2-4 แต่ฟอร์มของแข้งดาวรุ่งอย่าง Yotsakorn Burapha, Kakana Khamyok และ Seksan Ratree ทำให้อนาคตของทัพช้างศึกยังน่าจับตา
ไทยออกนำก่อนจาก Yotsakorn Burapha ในนาทีที่ 12 ซึ่งสุดท้ายเจ้าตัวได้รับเลือกเป็น Young Player of the Tournament จากผลงานตลอดรายการ จากนั้น Kakana Khamyok ได้จุดโทษทันทีหลังเริ่มครึ่งหลัง แต่ยิงข้ามคานออกไปอย่างน่าเสียดาย
เวียดนามตีเสมอได้ในนาทีที่ 52 จากจังหวะที่ลูกยิงของ Hêndrio ชนเสาแล้วมาโดน Chatchai Budprom เข้าเป็นประตูตัวเอง ก่อนที่ไทยจะนำอีกครั้งจาก Wanchai Jarunongkran ช่วงท้ายเกม ทว่าช่วงทดเวลาบาดเจ็บ Wanchai กลับสกัดพลาดจนกลายเป็นประตูตัวเองลูกที่สอง ส่งให้เวียดนามปิดบัญชีคว้าแชมป์สมัยที่
